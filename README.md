# 👨‍💻 About Me

Hi, I'm **Harun Ar Rashid**, a **Full Stack Developer** from **Dhaka, Bangladesh 🇧🇩**.

I build **SaaS platforms, CRM systems, AI-powered web apps, e-commerce platforms, and custom business applications** using **React.js, Next.js, Node.js, Express.js, and MongoDB**.

My focus is simple: create clean, modern, scalable, and business-ready web applications that help real users and real businesses move faster.

- 🛒 Built **ShopVerse E-Commerce Platform** with full-stack shopping features
- 🩺 Built **ShebaSathi Service Platform** for service booking and management
- 🤖 Interested in **AI-powered workflows, automation, and smart web products**
- 🔐 Comfortable with **authentication, REST APIs, dashboard UI, database models, and deployments**
- ⚡ Focused on **Clean Code, Modern UI, Performance, and Business Results**
